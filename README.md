# همّ هيتلمّ — PWA
## النشر (مجاني، HTTPS تلقائي)
Netlify: ادخل app.netlify.com/drop واسحب فولدر `hm-planner` كله. هتاخد رابط https جاهز.
GitHub Pages: ارفع الملفات لريبو، Settings → Pages → Deploy from branch (main / root).
## التثبيت على أندرويد
افتح الرابط في Chrome → ⋮ → "تثبيت التطبيق" (Install app) أو "إضافة إلى الشاشة الرئيسية". لازم HTTPS (أو localhost) عشان الـ Service Worker والتثبيت يشتغلوا. افتحه مرة بنت أونلاين عشان يتخزن للأوفلاين.
## النسخ الاحتياطي
المزيد → الإعدادات → تصدير JSON. للاسترجاع: استيراد ثم اختيار الملف (بيحذّرك قبل الاستبدال ويرفض الملفات غير الصالحة).
